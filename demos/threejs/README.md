# Three.js Skills — runnable demo

Repo: https://github.com/cloudai-x/threejs-skills (targets three.js r186)

Open `threejs-demo.html` in a browser (needs internet for the
three.js CDN). It is a real WebGL scene built with the current API:

- `WebGLRenderer` + `PerspectiveCamera` + `Scene`
- `BoxGeometry` + `TorusGeometry` + `MeshStandardMaterial`
- physical lights, `OrbitControls`, `setAnimationLoop`
- resize handling + pixel-ratio cap

Install the skill:

```bash
npx skills add cloudai-x/threejs-skills
```

Watch the video demo: `videos/09_threejs-skills.mp4`
