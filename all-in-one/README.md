# সব স্কিল এক জায়গায়

হ্যাঁ — ১০টি স্কিল তিনভাবে এক জায়গায় করা হয়েছে:

## ১. একটা কম্বাইন্ড ভিডিও (৪ মিনিট)

**`all-skills-combined.mp4`** — ১০টি ভিডিও একটার পর একটা জোড়া দিয়ে
একটি ৪:০০ মিনিটের ভিডিও (1280×720, H.264)। ০৩ নম্বর ভার্টিকাল ভিডিওটি
কালো বারসহ ১৬:৯-এ ফিট করা হয়েছে যাতে জোড়া লাগে।

- বাংলা সাবটাইটেল: **`all-skills-combined.bn.srt`** (৫০টি কিউ, মার্জ করা)
- বানানো হয়েছে: `concat.txt` লিস্ট দিয়ে ffmpeg concat (re-encode)

## ২. একটা গ্যালারি পেজ (সব ভিডিও এক পেজে)

**`index.html`** খুললেই সব দেখা যাবে:

- উপরে কম্বাইন্ড ভিডিও প্লেয়ার (বাংলা সাবটাইটেল ট্র্যাকসহ)
- নিচে ১০টি আলাদা ভিডিও কার্ড — প্রতিটিতে প্লেয়ার, GitHub লিংক,
  MP4 ডাউনলোড ও বাংলা সাবটাইটেল লিংক

ব্রাউজারে খুলুন: `index.html` (সার্ভার ছাড়াই ফাইল হিসেবে চলবে,
অথবা `python3 -m http.server` দিয়ে সার্ভ করুন)।

## ৩. একটা ইউনিফাইড স্কিল ফোল্ডার

**`skills/`** — ১০টি স্কিল একসাথে ইনস্টল করার নির্দেশ:

- `skills/README.md` — skills.sh CLI ও git clone নির্দেশ
- `skills/install-all-skills.sh` — এক কমান্ডে সব ইনস্টল:
  ```bash
  bash skills/install-all-skills.sh
  ```

## ফাইল তালিকা

| ফাইল | কী |
|---|---|
| `all-skills-combined.mp4` | ১০টি স্কিলের ৪ মিনিটের কম্বাইন্ড ভিডিও |
| `all-skills-combined.bn.srt` | কম্বাইন্ড ভিডিওর বাংলা সাবটাইটেল |
| `index.html` | সব ভিডিওর গ্যালারি পেজ |
| `skills/` | সব স্কিল একসাথে ইনস্টলের নির্দেশ + স্ক্রিপ্ট |
| `concat.txt` | কম্বাইন্ড ভিডিও বানানোর লিস্ট |
| `_03_normalized.mp4` | ভার্টিকাল ভিডিওর ১৬:৯ নরমালাইজড কপি (মধ্যবর্তী) |

সবগুলোকে এক জায়গায় জড়ো করেছে।
