Claude.ai / Claude Code-এর **Skills আপলোডে প্রতিটি জিপ ২ MB-এর কম** হতে হয় এবং

## কীভাবে আপলোড করবেন

1. নিচের তালিকা থেকে একটার পর একটা জিপ ডাউনলোড করুন (ক্লিক করলেই নামবে)
2. Claude.ai → **Settings → Capabilities → Skills** → **Upload skill** → জিপটি দিন
3. একইভাবে সবগুলো আপলোড করুন (Claude.ai একবারে একটি জিপ নেয়)
4. Claude Code ব্যবহার করলে একটাই কমান্ড:
   ```bash
   git clone --branch arena/90113f82-new-progect https://github.com/mdmukul120/New-progect.git
   bash New-progect/all-in-one/claude-skills/install-from-claude-zips.sh
   ```
