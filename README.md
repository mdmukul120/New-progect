# হাইব্রিড চ্যাট · Ollama + OpenRouter ফ্রি

বিল্ড স্টেপ ছাড়া বাংলা চ্যাট UI (`index.html`) এবং Vercel serverless API (`api/`)।
ডিফল্ট **সার্ভার-মোডে** OpenRouter key ব্রাউজারে আসে না।
লোকালি চালালে **Ollama** (আনলিমিটেড ফ্রি), হোস্ট করলে **OpenRouter-এর ফ্রি মডেল** (`:free`)।
মোবাইল ব্রাউজারেও কাজ করে।

> ব্যবহার: `index.html` ডাবল-ক্লিক করে খুলুন, অথবা `python3 -m http.server 8000` চালিয়ে `http://localhost:8000`-এ যান।

## ২. ২ মিনিটে শুরু (ফোন থেকেও)

1. [openrouter.ai/keys](https://openrouter.ai/keys)-এ সাইনআপ করুন — **কার্ড লাগে না**।
2. একটা ফ্রি key তৈরি করুন (`sk-or-v1-…`)।
3. এই সাইট খুলে উপরে ডানে ⚙ **সেটিংস** → প্রোভাইডার **OpenRouter** → key পেস্ট করুন।
4. **↻** চাপুন (মডেল তালিকা আসবে) → একটা মডেল বাছুন → **সংরক্ষণ**।
5. চ্যাট শুরু করুন।

সবকিছু শুধু আপনার ব্রাউজারে সংরক্ষিত থাকে (`localStorage`)। key কোথাও পাঠানো হয় না, শুধু OpenRouter-এ।

## ৩. Ollama লোকাল (আনলিমিটেড ফ্রি)

### ইনস্টল
- **macOS**: [ollama.com/download](https://ollama.com/download) → `ollama pull qwen3:8b`
- **Windows**: ইনস্টলার নামান, তারপর PowerShell-এ `ollama pull qwen3:8b`
- **Linux**: `curl -fsSL https://ollama.com/install.sh | sh`

### অ্যাপে যুক্ত করা
সেটিংস → **Ollama লোকাল** →
- বেস URL: `http://localhost:11434/v1`
- API key: `ollama` (যেকোনো লেখা চলবে)
- ↻ চেপে মডেল বাছুন

### ⚠️ যে দুটো জিনিস মানুষ আটকে যায়

1. **ডিভাইস**: Ollama আপনার কম্পিউটারে চলে। তাই পেজটাও **সেই কম্পিউটার থেকেই** খুলতে হবে
   (`http://localhost:8000`)। ফোনের ব্রাউজার আপনার কম্পিউটারের `localhost` দেখতে পায় না — ফোনের `localhost` মানে ফোন নিজেই।
2. **অরিজিন / CORS**: Ollama ডিফল্টে শুধু `localhost`, `127.0.0.1`, `file://` থেকে আসা রিকোয়েস্ট মানে।
   - `http://localhost:8000` বা ফাইল ডাবল-ক্লিক → **কিছু করতে হবে না**, সোজা কাজ করবে।
   - LAN IP দিয়ে খুললে (`http://192.168.0.5:8000`) → CORS খুলতে হবে:
     ```bash
     # macOS/Linux
     OLLAMA_ORIGINS="http://192.168.0.5:8000" ollama serve
     # Windows PowerShell (তারপর Ollama রিস্টার্ট)
     setx OLLAMA_ORIGINS "*"
     ```
   - হোস্ট করা সাইট (`https://…`) থেকে লোকাল Ollama-তে যাওয়া Chrome-এর *Private Network Access* নীতিতে সাধারণত ব্লক হয় — তাই লোকাল ব্যবহারে সাইটটা লোকালি খুলুন।

### RAM অনুযায়ী মডেল

| RAM | মডেল | মন্তব্য |
|---|---|---|
| ৪ GB | `qwen3:0.6b`, `llama3.2:1b` | হালকা, দ্রুত, বুদ্ধি কম |
| ৮ GB | `qwen3:4b`, `llama3.2:3b`, `gemma3:4b` | দৈনন্দিন ব্যবহারের সেরা ভারসাম্য |
| ১৬ GB | `qwen3:8b`, `gemma3:12b` | ভালো কোয়ালিটি |
| ৩২ GB+ | `qwen3:14b`, `gpt-oss:20b` | ক্লাউডের কাছাকাছি |

টিপস: প্রথমবার মডেল ডাউনলোড হতে কয়েক GB লাগবে (একবারই)। এরপর ইনফারেন্স **সম্পূর্ণ ফ্রি, আনলিমিটেড, অফলাইনেও**।

## ৫. হোস্ট করা (ঐচ্ছিক)

সার্ভার-মোডের জন্য Vercel প্রয়োজন। স্ট্যাটিক হোস্টে সরাসরি OpenRouter/Ollama মোড বেছে নিন।

**Vercel**
```bash
npm i -g vercel
vercel          # প্রম্পটে Enter চাপুন
```
অথবা GitHub-এ পুশ করে [vercel.com/new](https://vercel.com/new) → রিপো ইমপোর্ট → **Framework Preset: Other**, Build Command খালি, Output Directory ডিফল্ট রাখুন।
Environment Variables-এ **OPENROUTER_API_KEY** গোপন/encrypted হিসেবে যোগ করে Deploy করুন।
আগে deploy হয়ে থাকলে variable যোগ করার পর Redeploy করুন। পুরোনো Next.js project-এর সেটিং সরাসরি ব্যবহার করবেন না।

**নিরাপত্তা:** চ্যাটে প্রকাশ করা key revoke করে নতুন key সরাসরি Vercel dashboard-এ বসান; Git বা HTML-এ নয়।
সার্ভারে শুধু `:free` এবং `openrouter/free` মডেল অনুমোদিত; সর্বোচ্চ ৩০০০ output tokens।
IP-ভিত্তিক ৫ মিনিটে ৩০টি limit শুধু instance-প্রতি best effort—পাবলিক সাইটে শক্ত সুরক্ষা নয়।
ব্যক্তিগত ব্যবহারের জন্য deployment protection রাখুন; উন্মুক্ত করলে login ও distributed rate limiter দরকার।

**Netlify**: [app.netlify.com/drop](https://app.netlify.com/drop)-এ ফোল্ডারটা ড্র্যাগ করুন।
**GitHub Pages**: Settings → Pages → Branch `main` / folder `/ (root)` → Save।

হোস্ট করার পর মনে রাখুন: সাইট ক্লাউডে, Ollama আপনার পিসিতে — তাই হোস্টেড ভার্সনে OpenRouter ব্যবহার করুন,
আর লোকাল Ollama-র জন্য সাইটটা নিজের কম্পিউটার থেকেই খুলুন।

## ৬. সমস্যা সমাধান

| যা দেখছেন | কারণ | সমাধান |
|---|---|---|
| `Failed to fetch` (Ollama) | Ollama চলছে না / CORS | `ollama serve` চালু আছে কিনা দেখুন, `curl http://localhost:11434/api/tags`, তারপর `OLLAMA_ORIGINS` |
| `HTTP 401` | key ভুল/মেয়াদোত্তীর্ণ | নতুন key নিন |
| `HTTP 402` | এই মডেলে ক্রেডিট নেই | `:free` মডেল বাছুন |
| `HTTP 429` | ফ্রি লিমিট শেষ | ০০:০০ UTC পর্যন্ত অপেক্ষা বা লোকাল Ollama |
| `HTTP 404` | মডেলের নাম ভুল | সেটিংসে ↻ চেপে তালিকা থেকে বাছুন |
| মডেল তালিকা খালি | key দেওয়া হয়নি / নেটওয়ার্ক | "সংযোগ পরীক্ষা" চাপুন, বাংলায় কারণ দেখাবে |
| উত্তর আসছে না, কী-বোর্ড বন্ধ | মোবাইলে Enter = নতুন লাইন | পাঠাতে ▶ বাটন চাপুন |

## ৭. প্রাইভেসি

- কোনো অ্যাকাউন্ট নেই, কোনো কুকি নেই, কোনো টেলিমেট্রি নেই, কোনো অ্যানালিটিক্স নেই।
- চ্যাট ও সেটিংস `localStorage`-এ থাকে। সরাসরি OpenRouter মোডে নিজের key-ও সেখানে থাকে; সার্ভার-মোডে সাইটের key শুধু environment variable-এ থাকে।
- সার্ভার-মোডে কথোপকথন সাইটের API হয়ে OpenRouter-এ যায়; সরাসরি মোডে ব্রাউজার থেকে প্রোভাইডারে যায়।
- পাবলিক কম্পিউটারে ব্যবহারের পর ব্রাউজার ডেটা ক্লিয়ার করুন (key সংরক্ষিত থাকে)।

## ৮. ডেভেলপমেন্ট / টেস্ট

```bash
python3 -m http.server 8000     # লোকাল সার্ভার
npm i --no-save jsdom
node tests/smoke.test.js   # ২২টি স্মোক টেস্ট
node tests/api.test.js     # ২৪টি API ও পূর্ণ-স্ট্যাক মক টেস্ট
```

`tests/smoke.test.js` একটা মক OpenAI-সামঞ্জস্যপূর্ণ সার্ভার তুলে স্ট্রিমিং, মার্কডাউন, এরর হ্যান্ডলিং,
মডেল ফিল্টার, চ্যাট রিস্টোর ও ডিলিট — সব যাচাই করে।

কোড কোথায় কী:
- `renderMarkdown()` — নির্ভরতা-মুক্ত মার্কডাউন → HTML (সবকিছু escape করা, XSS নিরাপদ)
- `endpoint()` / `modelsUrl()` — প্রোভাইডারভেদে URL ও হেডার
- `send()` — SSE স্ট্রিমিং, abort, এরর ম্যাপিং
- `hintForError()` — প্রতিটি এররের বাংলা ব্যাখ্যা
