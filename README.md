## 📱 APK পাওয়ার ৩টি উপায় / 3 Ways to Get the APK

### উপায় ১ — GitHub Actions (সবচেয়ে সহজ / easiest, no computer setup)

রিপোতে পুশ হলেই GitHub নিজে APK বিল্ড করে দেয়:

1. **Actions** ট্যাবে যান → **Build NovaCut Android APK** → **Run workflow**
2. বিল্ড শেষ হলে (≈৩ মিনিট) **Artifacts** থেকে `NovaCut-APK` ডাউনলোড করুন
3. অথবা রিলিজ পেজ থেকে `NovaCut-v1.0.apk` নিন
4. ফোনে ইনস্টল করুন (Settings → Install unknown apps অনুমতি দিন)

### উপায় ২ — Android Studio

1. [Android Studio](https://developer.android.com/studio) ইনস্টল করুন
2. `android/` ফোল্ডার **Open** করুন
3. **Build → Build Bundle(s)/APK(s) → Build APK(s)**
4. `android/app/build/outputs/apk/release/app-release.apk` ইনস্টল করুন

> কমান্ড-লাইনে: `cd android && gradle :app:assembleRelease`

### উপায় ৩ — এখনই ব্রাউজারে (PWA)

অ্যাপটি একটি Progressive Web App — ফোনের Chrome-এ খুলে **Add to Home screen** করলে অ্যাপের মতোই চলবে (অফলাইনসহ)।

## 🤖 AI টুলস কীভাবে কাজ করে / How the AI Tools Work

| টুল | প্রযুক্তি |
|---|---|
| **অটো এনহান্স** | ফ্রেম বিশ্লেষণ (luminance/saturation statistics) → অপটিমাল কালার অ্যাডজাস্টমেন্ট |
| **স্মার্ট সিন কাট** | ক্যানভাস হিস্টোগ্রাম ডিফ-ডিটেকশন → সিন পরিবর্তনে অটো-স্প্লিট |
| **অটো ক্যাপশন** | Web Speech API (মাইক্রোফোন-সহায়তায়) → টাইমড সাবটাইটেল |
| **অটো রিফ্রেম** | স্মার্ট অ্যাসপেক্ট ম্যানেজমেন্ট + ফোকাস পয়েন্ট ক্রপ |
| **অটো ভলিউম** | WebAudio পিক-অ্যানালাইসিস → লাউডনেস নরমালাইজেশন |
